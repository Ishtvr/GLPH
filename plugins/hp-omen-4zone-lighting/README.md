# HP OMEN Tastaturbeleuchtung (PerformanceHub Plugin)

Offizielles installierbares Plugin für die 4-Zonen-RGB-Tastaturbeleuchtung von HP OMEN Notebooks (`hp-omen-4zone-lighting`).

## Installation
1. In **PerformanceHub** unter **Einstellungen → Plugins** auf **„+ Plugin hinzufügen“** klicken und `hp-omen-4zone-lighting.perfhub-plugin` auswählen (oder diesen Ordner direkt in `%USERPROFILE%\.performance-hub\plugins\` ablegen und auf **„Neu laden“** klicken).
2. In der Plugin-Tabelle den Schalter von **`(inaktiv)`** auf **`(aktiv)`** stellen — der **Beleuchtung**-Reiter erscheint sofort in der Seitenleiste.
